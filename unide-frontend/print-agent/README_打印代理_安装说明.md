# HIPERA 自动打印小票代理 — 安装说明

这是一个跑在**店里那台 Win10 电脑**上的常驻小程序。它每隔几秒问一次后台
有没有新订单（已确认/已付款的），有就用 Xprinter XP-80T 打印小票并蜂鸣。

> 你现在在家也可以先把文件拷过去、把 `.env` 填好；真正测试要在店里、打印机
> 连着电脑时做。

---

## 0. 它是怎么工作的（30 秒看懂）

```
店里电脑(本程序) --每10秒--> 你的后端(Railway) --> 取"已确认+未打印"的订单
                                |
                            打印小票 + 蜂鸣
                                |
                            告诉后端"这单打过了"(防止重复打)
```

- 只打 `confirmed_at` 有值的订单：现金/货到/手动 Bizum 下单即确认；**Stripe 付款
  成功后**才确认。
- 每单只打一次（后端 `printed_at` 标记 + 本地 `printed.json` 双保险）。
- 断网、打印机关机都不会崩，会自动重试。

## 1. 装 Node.js（只需一次）

1. 打开 https://nodejs.org/
2. 下载 **LTS** 版本的 Windows 安装包（`.msi`，64 位）。
3. 双击安装，**一路点 Next**，默认选项即可（会自动加入系统 PATH）。
4. 验证：按 `Win + R`，输入 `cmd`，回车，在黑窗口里输入：
   ```
   node -v
   ```
   显示类似 `v20.x.x` 或 `v22.x.x` 就成功了。

---

## 2. 放置程序文件

1. 把整个 `print-agent` 文件夹拷到一个**好找、路径没有中文**的位置，建议：
   ```
   C:\hipera-print
   ```
   （也就是把 `print-agent` 里的所有文件放进 `C:\hipera-print`）

> ⚠️ 路径尽量别带中文/空格，省得出奇怪的问题。

---

## 3. 填配置文件 .env

1. 在 `C:\hipera-print` 里找到 `.env.example`，**复制一份**，把名字改成 `.env`
   （没有 `.example`）。
2. 用记事本打开 `.env`，填这几项：
   - `BACKEND_URL=https://hipera-shop-production.up.railway.app`（一般不用改）
   - `PRINT_AGENT_TOKEN=` 这里填**和 Railway 上一模一样**的那个令牌。
   - `PRINTER_NAME=XP-80C`（如果你在「控制面板 > 设备和打印机」里看到的名字
     不是 XP-80C，就改成你看到的**准确名字**）。
   - 其它项保持默认即可。
3. 保存。

> 怎么确认打印机名字？「控制面板 → 设备和打印机」里，热敏打印机图标下面那行字
> 就是名字。右键它 → 「设置为默认打印机」（如果还没设）。

---

## 4. 先测一张小票（店里、打印机连好时做）

1. 打开 `cmd`，进入程序目录：
   ```
   cd /d C:\hipera-print
   ```
2. 运行测试：
   ```
   node index.js --test
   ```
3. 正常的话：打印机会**吐出一张示例小票** + **蜂鸣几声**。
   - 没反应/报错 `Impresora ... no disponible`：检查打印机是否开机、有没有纸、
     `.env` 里 `PRINTER_NAME` 是不是写对了。
   - 小票上的中文/重音字乱码：把 `.env` 里（如果以后加了）编码相关项告诉我，
     一般默认 CP858 对西班牙语没问题。
   - 不响但能打：把 `.env` 里 `BUZZER_COUNT`/`BUZZER_DURATION` 调大，或先用
     默认值；个别机型蜂鸣指令不同，响不了告诉我，我换指令。

---

## 5. 正式运行

双击 `C:\hipera-print\start.bat`，会弹出一个黑色窗口并显示：
```
HIPERA — Agente de impresion en marcha
```
**这个窗口要一直开着**（最小化没关系，别关）。来新订单时会自动打印 + 蜂鸣，
窗口里也会打印日志。如果程序意外停了，`start.bat` 会 5 秒后自动重启它。

> 想停：关掉那个黑窗口，或在里面按 `Ctrl + C`。

---

## 6. 设置开机自动启动（推荐）

这样电脑开机/登录后会自动跑起来，不用每天手动双击。

### 方法 A：任务计划程序（最稳，推荐）

1. 按 `Win`，搜索「任务计划程序」并打开。
2. 右侧点「创建基本任务」。
3. 名称填 `HIPERA Print`，下一步。
4. 触发器选「**当前用户登录时**」，下一步。
5. 操作选「启动程序」，下一步。
6. 「程序或脚本」填：
   ```
   C:\hipera-print\start.bat
   ```
   「起始于（可选）」填：
   ```
   C:\hipera-print
   ```
   下一步 → 完成。
7. （可选，更稳）在任务列表里找到 `HIPERA Print` → 右键属性 →
   「设置」标签 → 勾选「如果任务失败，按以下频率重新启动」。

### 方法 B：启动文件夹（最简单）

1. 按 `Win + R`，输入 `shell:startup`，回车，会打开「启动」文件夹。
2. 把 `C:\hipera-print\start.bat` 的**快捷方式**拖进这个文件夹
   （右键 `start.bat` → 发送到 → 桌面快捷方式，再把快捷方式移进来）。

下次开机登录后就会自动启动。

---

## 7. 日常使用 & 排错

- **正常**：窗口开着，有单就打 + 响。
- **网断了**：不打印，窗口里会显示重试日志；网恢复后自动继续，不会漏单
  （订单一直在后端排队，等下次取到）。
- **打印机关机/没纸**：当前单不打，等下次循环重试；缺纸时打印机硬件本身也会响。
- **重复打印**？不会。后端 `printed_at` + 本地 `printed.json` 双重防重。
- **想看打了哪些**：窗口里的日志会写 `🧾 Impreso pedido #XXXX`。

有任何报错，把黑窗口里的红字截图发我。

## 文件说明（给好奇的你）

| 文件 | 作用 |
|------|------|
| `index.js` | 主程序（轮询循环） |
| `lib/config.js` | 读取 `.env` 配置 |
| `lib/api.js` | 调后端取单 / 标记已打印 |
| `lib/escpos.js` | 生成小票内容（ESC/POS 指令） |
| `lib/printer.js` | 把小票发给 Windows 打印机 |
| `lib/store.js` | 本地已打印记录（防重复） |
| `raw-print.ps1` | 真正发原始字节给打印机的小助手 |
| `start.bat` | 启动器（含自动重启） |
| `.env` | 你的配置（令牌等，**不要外传**） |
