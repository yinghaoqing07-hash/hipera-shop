# 手机远程访问设置（Cloudflare 隧道 + 登录门）

目标：手机上用一个网址 + 登录，就能看流程图、记想法、点面板。
安全底线：面板**还是只绑 127.0.0.1**，外面碰不到；cloudflared 在同一台
电脑上把它接出去，Cloudflare Access 当登录门，只有你登录的邮箱能进。

做完这套，你在手机浏览器打开 `https://jarvis.你的域名/flujo` 就能用。

---

## 你需要先有的（一次性）

1. **一个域名**，并且已经加到 Cloudflare（免费套餐就够）。
   - 店里网站要是已经有域名在 Cloudflare，用它的子域名（如 `jarvis.xxx.com`）就行。
   - 没有的话，Cloudflare 后台能直接买，一年十几块。
2. Cloudflare 后台打开 **Zero Trust**（也叫 Access，免费额度 50 人，够用）。

---

## 第一步：装 cloudflared（店里电脑，一次性）

下载 Windows 版：<https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/>
（选 `cloudflared-windows-amd64.exe`，改名成 `cloudflared.exe`，放到桌面或
`C:\cloudflared\` 都行。）

打开 PowerShell，登录一次（会弹浏览器让你选域名授权）：

```powershell
cd C:\cloudflared
.\cloudflared.exe tunnel login
```

## 第二步：建隧道并绑到面板端口

```powershell
.\cloudflared.exe tunnel create jarvis
.\cloudflared.exe tunnel route dns jarvis jarvis.你的域名
```

在 `C:\cloudflared\` 建一个 `config.yml`（记事本另存为，编码选 UTF-8）：

```yaml
tunnel: jarvis
credentials-file: C:\Users\你的用户名\.cloudflared\对应的-隧道ID.json
ingress:
  - hostname: jarvis.你的域名
    service: http://127.0.0.1:8765
  - service: http_status:404
```

（`tunnel create` 会打印隧道 ID 和 json 路径，填进去即可。）

## 第三步：加登录门（Cloudflare 后台，关键一步）

Zero Trust → Access → Applications → Add an application → Self-hosted：

- Application domain：`jarvis.你的域名`
- Policy：Action = Allow，规则选 **Emails**，填你自己的邮箱（可多填几个人）。

> 这一步**不能省**。没有它，隧道就是一个谁都能开的公网网址。加了它，
> 别人在 Cloudflare 那层就被挡住，根本到不了店里电脑。

## 第四步：把你的邮箱告诉面板（双保险）

编辑 `config.local.json`，在 `panel` 里加 `remotoEmails`（就是第三步允许的
那几个邮箱）：

```json
  "panel": {
    "port": 8765,
    "remotoEmails": ["你的邮箱@gmail.com"]
  },
```

这样即使有人绕过了登录门，面板自己也只认这几个邮箱，其余一律 403。
（本机直接开面板不带这个身份头，照常能用，不受影响。）

## 第五步：让隧道开机自启（这样店关了再开也在）

```powershell
.\cloudflared.exe service install
```

装成 Windows 服务后，电脑一开机 cloudflared 就自动连，不用手动开。

---

## 用起来

- 手机浏览器打开 `https://jarvis.你的域名/flujo` → 第一次让你登录（选第三步
  那个邮箱）→ 进去就是流程图，点节点能记想法。
- 想加到手机主屏：浏览器菜单里「添加到主屏幕」，就跟个 App 一样一点就开。
- 面板首页（大按钮那套）：`https://jarvis.你的域名/`

## 排查

- 打开网址一直转圈：看看店里电脑 bot 开着没、cloudflared 服务在不在运行
  （`services.msc` 里找 cloudflared）。
- 进去提示 403 no autorizado：登录的邮箱不在 `remotoEmails` 里，或没配对。
- 改完 `config.local.json` 记得重启 bot（stop-bot 再 start-bot）才生效。
